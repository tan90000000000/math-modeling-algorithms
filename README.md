# 数学建模常用算法

本仓库记录数学建模学习和美赛准备过程中编写的 Python 程序。目前包含层次分析法（AHP）和优劣解距离法（TOPSIS）的示例实现，可用于学习多指标评价与方案排序。

## 当前内容

| 文件 | 主要功能 |
| --- | --- |
| [AHP.py](AHP.py) | 对判断矩阵进行一致性检验，计算权重与综合排名，并进行简单的敏感性分析。 |
| [TOPSIS.py](TOPSIS.py) | 对多种类型的指标进行正向化、标准化和 TOPSIS 评价，并输出排名。 |
| [个人时间安排.xlsx](个人时间安排.xlsx) | AHP 示例工作簿，包含准则层及各准则下的判断矩阵。 |
| [20条河流的水质情况数据.xlsx](20条河流的水质情况数据.xlsx) | TOPSIS 示例工作簿，`Sheet1` 包含 20 条河流的水质数据。 |
| [.gitignore](.gitignore) | 排除常见缓存、虚拟环境、临时文件及部分本地敏感配置。 |

**使用范围：**当前 AHP 程序基于个人时间安排案例，工作表名称和矩阵列范围固定；TOPSIS 程序通过命令行交互读取数据。它们适合学习和改造，并非无需修改即可适用所有问题的通用工具。

## 环境准备

需要 Python 3，以及以下依赖：

- `numpy`：数值计算。
- `pandas`：读取和处理表格。
- `matplotlib`：绘制 AHP 敏感性分析图。
- `openpyxl`：支持读取 `.xlsx` 工作簿。

在终端中运行：

```bash
git clone https://github.com/tan90000000000/math-modeling-algorithms.git
cd math-modeling-algorithms
python -m pip install numpy pandas matplotlib openpyxl
```

如果已经有本地仓库，只需进入对应目录并安装依赖。

## 一、层次分析法（AHP）

`AHP.py` 以个人时间安排为示例，对 4 个准则及 6 个备选方案进行评价。程序分别使用算术平均法、几何平均法和特征向量法计算权重，并给出综合排名。

### 1. 准备输入数据

仓库提供示例工作簿 [`个人时间安排.xlsx`](个人时间安排.xlsx)，与脚本的默认输入文件名一致。也可以按下列格式准备自己的工作簿，并在运行时指定文件。

工作簿需要包含以下工作表：

| 工作表名称 | 读取内容 | 数据范围 |
| --- | --- | --- |
| `准则层` | 4 个准则的名称及两两比较判断矩阵 | 名称在 A2:A5，矩阵在 B2:E5 |
| `时间紧迫性` | 6 个方案在该准则下的判断矩阵 | 方案名称在 A2:A7，矩阵在 B2:G7 |
| `长期价值` | 6 个方案在该准则下的判断矩阵 | 方案名称在 A2:A7，矩阵在 B2:G7 |
| `沉没成本` | 6 个方案在该准则下的判断矩阵 | 方案名称在 A2:A7，矩阵在 B2:G7 |
| `身体健康` | 6 个方案在该准则下的判断矩阵 | 方案名称在 A2:A7，矩阵在 B2:G7 |

每张表的第 1 行作为表头，程序从第 2 行开始读取。准则层的行、列顺序应与上面四张方案判断矩阵的顺序一致；各方案表中的方案顺序也应保持一致。

判断矩阵应为数值型的正互反矩阵：对角线为 1，且 `aᵢⱼ = 1 / aⱼᵢ`。例如，三分之一可填写为数值 `0.333333`。

### 2. 运行

在仓库目录下运行：

```bash
python AHP.py
```

默认读取当前工作目录中的 `个人时间安排.xlsx`。也可以传入自备工作簿的路径：

```bash
python AHP.py "ahp_data.xlsx"
```

程序会对每个判断矩阵进行一致性检验。当一致性比率 `CR ≥ 0.1` 时，当前实现会抛出错误并停止，需要调整对应判断矩阵。

### 3. 输出

- 终端：各层权重、三种方法的综合排名及敏感性分析统计。
- `ahp_results.csv`：三种方法得到的方案综合得分。
- `sensitivity.png`：敏感性分析中各方案获得第一名的次数。

敏感性分析默认对判断矩阵进行最多 ±20% 的随机扰动，尝试 1000 次，并跳过一致性检验未通过的模拟；该部分使用算术平均法计算权重。若没有有效模拟，当前代码可能出现除零错误，需要调整输入或扰动设置。

## 二、优劣解距离法（TOPSIS）

`TOPSIS.py` 适用于多个评价对象、多个数值指标的排序。当前程序支持效益型、成本型、中间型和区间型指标；运行脚本时默认使用等权重。

### 1. 准备输入数据

仓库提供示例工作簿 [`20条河流的水质情况数据.xlsx`](20条河流的水质情况数据.xlsx)，其 `Sheet1` 包含 20 个评价对象和 4 个水质指标。也可以自行准备 `.xlsx` 文件：工作表必须命名为 `Sheet1`，第一行为列名，第一列为评价对象，其余列为数值指标。例如：

| 方案 | 效益 | 成本 |
| --- | ---: | ---: |
| 方案 A | 9 | 4 |
| 方案 B | 7 | 2 |
| 方案 C | 8 | 3 |

此表仅用于说明格式；仓库中的河流水质工作簿可作为现成输入。程序只读取 `Sheet1`，不会读取其中其他工作表。

### 2. 运行

```bash
python TOPSIS.py
```

按提示输入 Excel 文件名或路径，随后为每个指标选择类型：

| 输入 | 指标类型 | 说明 |
| --- | --- | --- |
| `1` | 效益型 | 越大越好 |
| `2` | 成本型 | 越小越好 |
| `3` | 中间型 | 越接近指定值越好；按提示输入最优值 |
| `4` | 区间型 | 位于指定区间内最好；按提示输入区间上下限 |

使用仓库的示例数据时，在文件名提示处输入 `20条河流的水质情况数据.xlsx`，再依据评价目标为四个指标选择类型。若使用上表的“效益”和“成本”示例，则分别输入 `1` 和 `2`。输入文件路径时无需额外输入引号。

### 3. 输出与权重

程序在终端输出正向化矩阵、标准化矩阵、各方案得分及排名，同时生成 `topsis_results.csv`。CSV 保留输入时的方案顺序；终端按得分从高到低输出排名。

`topsis(Z, weights=None)` 函数支持传入自定义权重，但当前交互流程没有权重输入步骤，需要修改调用代码。传入的权重应与指标列一一对应、非负且总和为 1；当前代码仅检查权重和。

## 使用时的注意事项

- 仓库提供两份示例工作簿；更换输入文件时，请按照工作表名称、列顺序和数据类型填写。
- TOPSIS 中，如果某列正向化后全为 0，或所有方案与理想解、负理想解的距离都为 0，计算可能出现除零或 `NaN`；请检查输入数据和指标设置。
- 运行结果写入当前工作目录，同名结果文件可能被覆盖。如需保留某次结果，请先另存。
- 当前 AHP 的工作表结构和矩阵大小在代码中固定，迁移到其他问题时，需要根据实际层次结构修改读取范围与相关配置。
